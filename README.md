# construction-blog-page-

Construction Blog 🏗️

I have built a construction blog website using the MERN stack.

The website allows users to register and login with JWT and bcrypt authentication. After logging in, users can create, update and delete blog posts using CRUD operations.

Each blog is displayed as a card, and users can click Read More to view the complete blog post.

Technologies Used

MERN Stack

React.js #frontend 

Node.js
              # backend 
Express.js
              
MongoDB      # database 

Mongoose     #backend to communicate database

Axios        #frontend to communicate backend

JWT          
              #for admin auth
bcrypt

Tailwind CSS    #style 

Features

User login and authentication

Create, read, update and delete blogs

Read more option for each blog

Secure password authentication using bcrypt

JWT-based authentication

Responsive UI using Tailwind CSS

API communication using Axios

This project helped me practice building a complete full-stack blog application with authentication, database integration and CRUD functionality.
